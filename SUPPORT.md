# Support

## Questions and ideas

Use [GitHub Discussions](https://github.com/sparshsam/openresume/discussions) for questions, workflow ideas, and show-and-tell.

## Bugs and feature requests

Open an issue using the provided templates. Include the browser, operating system, and the structured text needed to reproduce the problem. Remove any personal content before posting.

## Security

Do not file security issues publicly. Follow [SECURITY.md](SECURITY.md).

## Scope

Support covers the current `0.x` line and the documented input format. There is no hosted service, account, or cloud storage to support.
