# OpenResume generated icons

`icon-source.png` is a byte-identical copy of the light-mode master in
[`assets/branding/source-assets`](../branding/source-assets/). It satisfies the
Kovina canonical-source path while the separate light and dark masters remain
authoritative.

Generated assets are written by [`scripts/generate-icons.py`](../../scripts/generate-icons.py):

- `light/` — favicons, Apple touch icons, Microsoft tile, and 192/512 application icons.
- `dark/` — theme-specific favicons and 192/512 application icons.

Do not hand-edit these files. Run the script instead. The runtime subset is
copied into `public/`; the full pipeline and inventory are documented in
[`docs/branding.md`](../../docs/branding.md).
